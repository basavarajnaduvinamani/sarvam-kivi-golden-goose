# Evidence

This directory contains browser-captured screenshots demonstrating Kivi's working local interface across all five product surfaces.

These screenshots verify that the described product behaviors are real and observable. They do not replace the reproducible reviewer path documented in [RUN.md](../RUN.md) — reviewers are encouraged to follow the runbook and observe the application firsthand.
